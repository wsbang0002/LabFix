    1. 서비스 지원 범위

    • Arduino: Arduino Uno R3 기준 (컴파일, 업로드, 보드/포트 선택, 시리얼 통신 문제)
    • Python: Python 3.x 기준 (SyntaxError, IndentationError, NameError, TypeError, ModuleNotFoundError, FileNotFoundError, 실행/패키지 설치 환경 격차)

    2. Gemini AI 오류 분석 및 안전성

    • Serverless 연동: API 키는 브라우저에 전달되지 않으며 Vercel 서버 함수(/api/analyze)를 거쳐 백엔드에서 안전하게 호출됩니다.
    • 구조화된 검증: 모든 AI 응답은 서버 측 JSON Schema 검증 및 필드 규칙 검사를 통과한 항목만 표출됩니다.
    • 데이터 격리: 입력된 로그 속 지시문(Prompt Injection)은 AI에게 전달되는 명령이 아니라 오직 분석 대상 데이터로 다루어집니다.

    3. 안전 수칙 및 민감 정보 보호

    ⚠️ 주의: API 키, 비밀번호, 개인 서버 URL, 토큰 등이 포함된 로그나 코드는 반드시 삭제한 후 붙여넣으세요.

    • 로컬 전용 저장: 모든 해결 기록은 사용자의 웹 브라우저 내 localStorage에만 저장되며 외부 서버로 전달되지 않습니다.
